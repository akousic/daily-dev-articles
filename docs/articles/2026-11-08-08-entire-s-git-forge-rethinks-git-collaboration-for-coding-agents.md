## Summary

Entire is a Git forge designed specifically for collaboration between human developers and AI coding agents. Its premise is that traditional software development infrastructure, particularly the pull request (PR) model, is not well suited to an environment where AI agents generate, review, and iterate on code at high speed. As Thomas Dohmke, former GitHub CEO and currently CEO of Entire, explains, GitHub and GitLab transformed human-to-human collaboration by centering it around asynchronous code reviews and version control.

## Key Takeaways

- A multi-agent forge, by contrast, centers around the asynchronous orchestration, versioning, and auditing of AI agents working alongside humans.
- Built on top of a fully distributed architecture that enables pushes up to 89 times faster than GitHub, Entire's core component is trails, which addresses the challenges AI coding agents pose to the traditional PR-based development model: The pull request [timeline] has become an audit log that only the agent reads.
- It does not provide the information for the developer to decide whether they can merge with confidence.
