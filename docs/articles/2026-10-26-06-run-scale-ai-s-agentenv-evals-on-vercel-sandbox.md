## Summary

AgentEnv, Scale AI's framework for testing agents against tasks and scoring their results, now runs on Vercel Sandbox. The Vercel provider ships in AgentEnv 0.9.1334 and later, and runs the agent and its task environment in separate Sandboxes. Try the AgentEnv example to run an evaluation on Vercel Sandbox and inspect the task’s score and the agent’s recorded actions.

## Key Takeaways

- After completing the setup guide, run this command from the cloned repository.
- It uses your existing Vercel CLI login: ./vercel-eval --scope YOUR_TEAM --project YOUR_PROJECT Replace YOUR_TEAM with your Vercel team slug and YOUR_PROJECT with an existing project name.
- Learn more in the Sandbox ecosystem documentation.
