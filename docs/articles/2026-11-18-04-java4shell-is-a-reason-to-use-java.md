## Summary

We're less than a day into dealing with "Java4Shell", an issue stemming from how the Java Virtual Machine intrinsifies Base64 encoding code. If you have a Java deployment you haven't updated yet, add -XX:-UseBASE64Intrinsics to the VM flags. Then upgrade your VM to a version where the issue is patched when you can.
