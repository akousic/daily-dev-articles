## Summary

Grafana Labs has released Grafana 13.3 with cross-dashboard variables that let teams manage shared dashboard controls in one place. The release also introduces Notebooks for collecting panels and investigation notes in a document that colleagues can share. The release announcement describes cross-dashboard variables as a public preview across all Grafana editions.

## Key Takeaways

- Teams can define a variable once and use it in multiple dashboards, avoiding separate configurations for a selector such as an environment or a region.
- Grafana says managing those copies separately can lead to configuration drift.
- Cross-dashboard variables address a longstanding user request.
