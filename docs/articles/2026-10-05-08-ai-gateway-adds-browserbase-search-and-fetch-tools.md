## Summary

Browserbase Search and Fetch are now available through AI Gateway. Give your models access to current information, find relevant pages, and retrieve their contents, alongside Browserbase's existing AI SDK and Vercel Marketplace integrations. AI Gateway lets you use Browserbase's tools across model providers with one API key.

## Key Takeaways

- Add web search and page retrieval to any model that supports tool calling, and keep the same tools when you switch models.
- These helpers are available in AI SDK 7.0.116 and later.
- Update with pnpm add ai@latest and set your AI_GATEWAY_API_KEY.
