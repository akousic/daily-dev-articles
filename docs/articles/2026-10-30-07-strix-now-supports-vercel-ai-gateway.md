## Summary

Strix, the open-source AI penetration testing tool, can now run on any of the 400+ models on Vercel AI Gateway. Strix can reach models from Anthropic, OpenAI, Kimi, GLM, Deepseek, and others through a single API with no markup, removing the need to sign up for multiple providers. Usage and cost are tracked across all models in AI Gateway.

## Key Takeaways

- Strix selects the Gateway through STRIX_LLM, where the model is the standard AI Gateway <provider>/<model> ID behind a vercel_ai_gateway/ prefix: terminal export STRIX_LLM="vercel_ai_gateway/zai/glm-5.3"export LLM_API_KEY="your-ai-gateway-api-key" See Strix's AI Gateway setup guide to configure it and get started today.
