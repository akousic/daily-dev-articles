Somewhere in the last couple of years, a strange feeling crept in, and I don't think I'm the only one who's felt it. It's the sense that I'm not really supposed to enjoy this anymore. That admitting, out loud, in 2026, that I love programming — that I'll happily lose a Saturday to a problem a machine could solve in four seconds — is a little naive.
