Wiz Research uncovered multiple critical vulnerabilities in core PHP, a popular general-purpose scripting language that powers 70% of all websites in the world. ## Key Takeaways

- These vulnerabilities include memory disclosure and unauthenticated remote code execution in PHP itself, independent of the application running on top of it, putting every affected website in immediate risk.
- Every PHP version released in the last decade is affected by at least one of these vulnerabilities, going back to version 5.4.
- Attackers can exploit them remotely, in some cases fairly easily.
