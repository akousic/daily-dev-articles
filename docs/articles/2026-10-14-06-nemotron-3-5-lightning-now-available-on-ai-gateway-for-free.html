Nemotron 3.5 Lightning now available on AI Gateway for free

Summary

Nemotron 3.5 Lightning from NVIDIA is now available for free on AI Gateway as nvidia/nemotron-3.5-lightning-free, served by NVIDIA. Nemotron 3.5 Lightning is an open-weight reasoning and chat model for long-running agents, sub-agent work, chatbots, and RAG systems. The model has 30B parameters with 3B active per token, in a hybrid Mixture-of-Experts design that interleaves Mamba-2 and MoE layers with a few attention layers.

Key Takeaways

  • It has a 1M token context window and supports tool calling and structured outputs.
  • Note: The provider may retain prompts for model improvement.
  • Call Nemotron 3.5 Lightning through the AI SDK, the Chat Completions, Responses, and Messages APIs, or a coding agent connected to AI Gateway.
