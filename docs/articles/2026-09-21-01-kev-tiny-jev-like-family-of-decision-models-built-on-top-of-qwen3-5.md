## Summary

Small Jev-like decision models you can train and run yourself. Kev is a family of small decision models built on Qwen3.5 and based on the architecture described in Jev's Architecture Unmasked. You can use the pretrained weights or train your own.

## Key Takeaways

- The API matches TypeSafe's System One, so you can point their Python SDK at your local server.
- - 0.8B, 4B, and 9B models, with training code and evaluation data.
- - Yes/no (noul ), multiple-choice (choice ), and rating (score ) questions in the same request.
