## Summary

AWS recently open-sourced Dogwood, a policy language for agent tool calls. What makes it different from Cedar is that its rules can look backward at what the agent already did. It ships under Apache 2.0, and AgentCore Policy supports it today.

## Key Takeaways

- AgentCore Policy launched at re:Invent last year.
- It sits outside the model as a deterministic control layer.
- The model proposes a tool call, the policy engine accepts or rejects it, and the model never touches enforcement.
