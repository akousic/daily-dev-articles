## Summary

Anthropic has outlined how the Claude Code team handles code reviews as AI agents increasingly contribute to its codebase. The approach relies on multiple layers of automated verification, AI-powered reviews, and risk-based human approval, aiming to reduce manual review time without increasing regressions or production incidents. Addy Osmani, Morgan Westlee Lunt and Qing Wang described how the team's review process has evolved alongside the growing volume of AI-generated code.

## Key Takeaways

- Between June and September, merged pull requests to the Claude Code repository more than doubled, while the proportion of changes requiring a revert fell by over 40%.
- Rather than relying on traditional line-by-line reviews, the team has moved much of the verification earlier in the development process.
- Before opening a pull request, Claude runs tests, builds, and linters, while a separate agent reviews the changes in a fresh context.
