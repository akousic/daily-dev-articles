## Summary

AWS Emulator is a local emulator of the AWS APIs. You use it to test your software without calling AWS, on your own machine, on a development server, or in continuous integration (CI). You don’t need an AWS account.

## Key Takeaways

- Your requests go to the emulator, not to AWS.
- So you work with emulated resources instead of AWS resources.
- AWS Emulator has no additional service fee.
