## Summary

AWS has recently released File Mover Express, an open-source application under the Apache 2.0 license for transferring large files between local systems and Amazon S3. Available for macOS, Windows, and Linux, it supports parallel transfers, automatic performance tuning, retries, pause and resume, and file integrity verification. Designed to "move media to S3 at wire speed," File Mover Express supports auto-tuned parallel transfers, pause and resume, a desktop GUI, a scriptable CLI, and automatic uploads from monitored folders.

## Key Takeaways

- The project is primarily developed in Go for its transfer engine and TypeScript with Angular for its graphical interface.
- It also supports integration with AI assistants through MCP and OIDC-based authentication with identity providers.
- Provanshu Dey, senior solutions architect at AWS, Asbjorn Kjaer, senior software engineer at AWS, Matthew Muccio, solutions architect at AWS, and Ross Dickson, senior customer solutions manager at AWS, explain: At the core of File Mover Express is a daemon-based transfer engine that decouples transfers from your desktop session.
