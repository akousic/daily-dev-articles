## Summary

Muse Ember from Meta is now available on AI Gateway. It is a lightweight reasoning model for the high-volume parts of an agent run, such as coding sub-tasks, tool calls, and document analysis. Muse Ember handles the bounded tasks agents repeat many times in a single run, like implementing a helper function, calling a tool, or summarizing a document.

## Key Takeaways

- The model accepts text, image, and video input with a 1M-token context window, so an agent can pass it code, screenshots, documents, and clips in the same run.
- Tool calling lets your application feed each result into the next step.
- Reasoning effort is adjustable from minimal to max.
