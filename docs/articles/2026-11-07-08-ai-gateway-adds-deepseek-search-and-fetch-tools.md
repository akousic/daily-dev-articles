## Summary

DeepSeek Search and DeepSeek Fetch are now available through AI Gateway. Search finds relevant pages with titles, URLs, and summaries. Fetch retrieves page content as Markdown for your model to read.

## Key Takeaways

- Use both tools with any model that supports tool calling, using one AI Gateway API key.
- No separate DeepSeek account is required, and you can keep the same tools when switching model providers.
- These helpers are available in AI SDK 6.0.321 and later on v6, or 7.0.160 and later on v7.
