7. Study Finds AI-generated Code Fails to Boost Productivity Due to Downstream Bottlenecks

InfoQRSS curated source

A recent Harvard study of 718 firms, using the Jellyfish analytics platform, finds that although AI coding assistants and agents increase code volume, this does not translate into a corresponding increase in completed work, partly because AI-generated code increases the workload in later stages of development, particularly code review. The study was based on approximately 300 million work events of 700,000 workers across 700+ firms from January 2021 to March 2026. The data was gathered from several sources such as HR information, code version control systems, issue management systems, scheduling tools such as Google Calendar, and generative-AI tools, including GitHub Copilot, Cursor, and Claude Code.
